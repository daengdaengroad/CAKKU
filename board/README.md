# 인건비 현황판 (cakku-board)

인건비 지원금 서류 제출·급여·사업주 4대보험을 월별로 관리하는 현황판과,
PC·폰이 같은 내용을 보게 해 주는 동기화 서버입니다.

**카꾸 앱(`server/`, `app/`)과는 아무 관계가 없습니다.** 코드도 배포도 계정도 공유하지 않습니다.
Cloudflare Workers + D1 위에서 돌고, 무료 한도 안에서 동작합니다.

## 배포 (처음 한 번)

Cloudflare 계정이 필요합니다. 카드 등록 없이 무료로 만들 수 있습니다.

```bash
cd board
npm install
npx wrangler login              # 브라우저가 열리고 계정 연결

npx wrangler d1 create cakku-board
```

마지막 명령이 `database_id = "..."` 를 찍어 줍니다. 그 값을 **`wrangler.jsonc` 의
`PUT-YOUR-D1-DATABASE-ID-HERE` 자리에 붙여넣으세요.** 그리고:

```bash
npm run db:init:remote          # 실제 DB에 테이블 생성
npm run deploy                  # 배포
```

배포가 끝나면 `https://cakku-board.<계정>.workers.dev` 같은 주소가 나옵니다.
그 주소를 PC와 폰에서 열면 됩니다.

배포 후 주소 뒤에 `/api/health` 를 붙여 열어 보세요. `{"ok":true,"storage":"d1"}` 이면 정상입니다.

## 고친 뒤 다시 올리기

```bash
npm run deploy
```

`public/index.html` 만 고쳤을 때도 같은 명령입니다.

## 로컬에서 띄워 보기

```bash
npm run db:init                 # 로컬 D1에 테이블 생성 (처음 한 번)
npm run dev                     # http://localhost:3100
```

로컬 D1 은 `.wrangler/` 안에 따로 있어서 실제 데이터와 섞이지 않습니다.

## 무료 한도

D1 무료 플랜은 하루 읽기 500만 행 / 쓰기 10만 행, 저장 5GB 입니다.
현황판은 저장 한 번에 1행을 쓰고 조회 한 번에 1행을 읽습니다.
사람 몇 명이 쓰는 정도로는 한도 근처에도 가지 않습니다.

## 동기화가 동작하는 방식

- 입력은 **언제나 그 기기 브라우저에 먼저** 저장됩니다. 서버가 죽어도 입력한 내용은 남습니다.
- 그 위에 **동기화 키** 하나로 기기를 묶습니다.
- 입력이 멎고 1.2초 뒤 올라가고, 화면을 다시 볼 때와 30초마다 받아옵니다.
- 입력 중에는 화면을 갈아끼우지 않습니다 — 커서가 튀지 않게.
- 두 기기가 같은 버전에서 각자 고쳤으면 조용히 덮어쓰지 않고 어느 쪽을 남길지 물어봅니다.
  판정은 SQL 의 `WHERE rev = ?` 안에서 이뤄지므로 동시에 들어와도 한쪽만 통과합니다.

### 로그인이 없습니다 — 키가 곧 비밀번호입니다

- 24자리 무작위 키(약 124비트)를 아는 쪽만 읽고 쓸 수 있습니다. 찍어서 맞히는 건 사실상 불가능합니다.
- 키는 주소창이나 링크에 실리지 않습니다. 기기마다 직접 입력하고, 그 브라우저에만 저장됩니다.
- 키 목록을 뽑아 주는 경로가 없고, 서버 로그에도 키를 남기지 않습니다.
- **키가 새면 급여 내용이 샙니다.** 공개 대화방 등에 붙여넣지 마세요.
  샌 것 같으면 `이 기기 내용으로 시작` 으로 새 키를 만들면 됩니다.
- 더 조이고 싶으면 Cloudflare 대시보드에서 Rate limiting 규칙이나 Cloudflare Access 를 얹을 수 있습니다.

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `GET` | `/api/health` | 동기화 지원 여부. 현황판이 이걸로 판단합니다. |
| `GET` | `/api/board/:key` | `{ rev, data, updatedAt }`, 없으면 404 |
| `PUT` | `/api/board/:key` | 본문 `{ rev, data, force }`. `rev` 가 어긋나면 409 + 서버 내용 |

## 같은 파일이 아티팩트로도 올라가 있습니다

`public/index.html` 은 Claude 아티팩트로도 게시돼 있습니다.
아티팩트에서는 외부 통신이 막혀 있어 `/api/health` 요청이 실패하고, 동기화 카드가 **숨겨진 채**
브라우저 저장 + `코드 복사 / 코드 입력` 으로만 동작합니다. 파일은 한 벌만 관리하면 됩니다.
