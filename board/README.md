# 인건비 현황판 (cakku-board)

인건비 지원금 서류 제출·급여·사업주 4대보험을 월별로 관리하는 현황판과,
PC·폰이 같은 내용을 보게 해 주는 작은 동기화 서버입니다.

**카꾸 앱 서버(`server/`)와는 완전히 별개입니다.** 코드도, 데이터베이스도, 배포도 공유하지 않습니다.

## 로컬에서 띄우기

```bash
cd board
npm install
npm start           # http://localhost:3100
```

`DATABASE_URL` 없이 띄우면 `board/.data/boards.json` 파일에 저장합니다. 개발용입니다.

## Railway 배포

카꾸와 **별도 서비스**로 만듭니다.

1. Railway 프로젝트에서 **New → GitHub Repo** 로 이 저장소를 고릅니다.
2. 서비스 설정에서 **Root Directory** 를 `board` 로 지정합니다. (이래야 카꾸 앱이 아니라 현황판이 뜹니다.)
3. 같은 프로젝트에 **New → Database → PostgreSQL** 을 추가합니다.
4. 현황판 서비스의 Variables 에서 `DATABASE_URL` 을 그 Postgres 의 값으로 연결합니다.
5. 배포 후 생긴 주소를 PC와 폰에서 엽니다.

`DATABASE_URL` 을 붙이지 않으면 컨테이너 파일에 저장되고 **재배포할 때마다 내용이 사라집니다.** 반드시 연결하세요.

## 동기화가 동작하는 방식

- 입력은 **언제나 그 기기 브라우저에 먼저** 저장됩니다. 서버가 죽어도 입력한 내용은 남습니다.
- 그 위에 **동기화 키** 하나로 기기를 묶습니다. 한쪽에서 고치면 다른 쪽이 화면을 열 때(또는 30초마다) 받아옵니다.
- 두 기기가 같은 버전에서 각자 고쳤으면 조용히 덮어쓰지 않고, 어느 쪽을 남길지 물어봅니다.

### 로그인이 없습니다 — 키가 곧 비밀번호입니다

- 24자리 무작위 키를 아는 쪽만 읽고 쓸 수 있습니다. 키는 주소창이나 링크에 실리지 않고, 직접 입력합니다.
- 서버는 키 목록을 뽑아 주는 API가 없고, 로그에도 키를 남기지 않습니다.
- 키를 무작위로 넣어보는 시도를 막기 위해 IP당 분당 요청 수와 "없는 키 조회" 횟수를 제한합니다.
- **키가 새면 급여 내용이 샙니다.** 메신저 공개 대화방 등에 붙여넣지 마세요. 샌 것 같으면 새 키로 다시 시작하면 됩니다(`이 기기 내용으로 시작`).

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `GET` | `/api/health` | 동기화 지원 여부. 현황판이 이걸로 판단합니다. |
| `GET` | `/api/board/:key` | `{ rev, data, updatedAt }`, 없으면 404 |
| `PUT` | `/api/board/:key` | 본문 `{ rev, data, force }`. `rev` 가 어긋나면 409 + 서버 내용 |

## 같은 파일이 아티팩트로도 올라가 있습니다

`public/index.html` 은 Claude 아티팩트로도 게시돼 있습니다.
아티팩트에서는 외부 통신이 막혀 있어 `/api/health` 요청이 실패하고, 동기화 카드가 **숨겨진 채**
브라우저 저장 + `코드 복사 / 코드 입력` 으로만 동작합니다. 파일은 한 벌만 관리하면 됩니다.
