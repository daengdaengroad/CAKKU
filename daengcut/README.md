# 댕컷 (DaengCut)

**반려견 영상만 넣으면 유튜브 숏츠가 나오는 자동 편집기.**
대본 작성 · 컷 편집 · 자막 · 내레이션 · 업로드까지 한 번에 처리하고,
마음에 안 드는 부분은 브라우저에서 직접 고칠 수 있습니다.

```
촬영한 영상  →  분석  →  대본  →  컷/자막/내레이션  →  [편집]  →  렌더  →  유튜브
```

## 왜 이런 구조인가

영상 렌더링은 서버에서 제일 비싼 작업입니다. 그래서 **한 코드베이스로 로컬과 서버 양쪽에서
돌아가도록** 만들었습니다. 혼자 쓸 때는 내 PC에서 공짜로 빠르게 돌리고,
나중에 서비스로 열 때 같은 코드를 서버에 올리면 됩니다.

## 시작하기

```bash
npm install
npm run setup     # .env 생성 + 한글 자막 폰트 다운로드
# .env 를 열어 ANTHROPIC_API_KEY 를 채운다
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

`ffmpeg` 은 npm 설치 시 함께 들어오므로 따로 설치하지 않아도 됩니다.

## 구성

| 폴더 | 역할 |
| --- | --- |
| `server/src/media` | ffmpeg 래퍼, 영상 분석(장면 전환·움직임·소리), 프레임 추출, 미리보기 생성 |
| `server/src/timeline` | 편집 문서(타임라인) 타입과 검증 스키마 |
| `server/src/render` | 자막(ASS) 생성, 프레이밍 계산, 최종 렌더 파이프라인 |
| `server/src/ai` | 비전 분석 → 대본 생성, TTS |
| `server/src/routes` | HTTP API |
| `web` | 편집 UI |

## 타임라인이 중심입니다

AI가 처음 한 벌 만들어주는 것도, 사용자가 UI에서 고치는 것도, 렌더러가 읽는 것도
전부 **하나의 타임라인 JSON**입니다. 같은 타임라인이면 언제 돌려도 같은 영상이 나옵니다.

```jsonc
{
  "clips":     [{ "sourceId": "...", "in": 3.0, "out": 8.0, "speed": 1, "framing": {...} }],
  "captions":  [{ "start": 0.2, "end": 2.4, "text": "오늘도 산책 나온 우리 강아지", "emphasis": true }],
  "narration": [{ "start": 0.2, "text": "...", "audioFile": "audio/n0.mp3" }],
  "meta":      { "title": "...", "description": "...", "tags": ["강아지", "쇼츠"] }
}
```

## 자막 폰트 바꾸기

`assets/fonts/` 에 `.ttf` / `.otf` 를 넣으면 자동으로 인식합니다.
한글 글리프가 실제로 들어있는지 폰트 파일을 직접 열어 확인하므로,
한글이 없는 폰트를 골라 자막이 네모로 깨지는 일은 없습니다.
